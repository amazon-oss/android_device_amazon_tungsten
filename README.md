Device configuration for Amazon Fire HD 10 (2023)
=================================================

The Amazon Fire HD 10 (2023) (codenamed _"tungsten"_) is a tablet from Amazon.

## Device specifications

| Basic                   | Spec Sheet                                               |
| ----------------------: | :------------------------------------------------------- |
| SoC                     | MediaTek MT8169                                          |
| CPU                     | Octa-core (2x2.05 GHz Cortex-A76 & 6x2.0 GHz Cortex-A55) |
| GPU                     | Mali-G52 MC2                                             |
| Memory                  | 3 GB                                                     |
| Storage                 | 32/64 GB, eMMC                                           |
| Expandable Storage      | microSDXC (dedicated slot)                               |
| Shipped Android Version | 11 (Fire OS 8)                                           |
| Display                 | 10.1 inches, 1200 x 1920 pixels, IPS LCD                 |
| Rear Camera             | 5 MP                                                     |
| Front Camera            | 5 MP                                                     |
